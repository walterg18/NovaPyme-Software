Preguntas Frecuentes

¿Qué es exactamente la Vitrina Simuladora?

Es un visualizador tecnológico para que puedas hacer clic y ojear todo nuestro programa sin dañar ninguna base de datos real. Te sirve para conocerlo ante de comprar.

¿Necesito ser un genio para usar el programa real?

No necesitas saber nada de computadoras. Todo el sistema está programado para ser tan fácil de usar como tu propio WhatsApp.

¿Cuanto tardan en instalarme la versión oficial en mi negocio?

Menos de 30 minutos. Nos conectamos contigo por computadora usando programas como TeamViewer o AnyDesk, lo instalamos y creamos tus usuarios rápidamente luego del pago.
